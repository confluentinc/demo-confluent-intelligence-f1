| [`reference/`](reference/) | The F1 scenario and other background material |

| [`demos/`](demos/) | Runbooks and files for one-off demos or recordings |
| [`assets/`](assets/) | Images and attendee-uploaded files |
| [`backup/`](backup/) | Compatibility pointers for older published links |
